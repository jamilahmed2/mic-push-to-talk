## Screenshot Guidelines

### Resolution
- Use 1920x1080 or higher resolution
- Capture at 100% DPI scaling
- PNG format for transparency support

### Content
- Clean desktop background (dark preferred)
- Show the feature clearly
- Include relevant UI elements
- Crop to relevant area

### Naming Convention
- Use lowercase with hyphens
- Be descriptive: `feature-description.png`
- Examples:
  - `overlay-muted.png`
  - `settings-window.png`
  - `tray-menu-open.png`
